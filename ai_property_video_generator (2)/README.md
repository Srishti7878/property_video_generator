# AI Property Video Generator - Homeland Mohali, Kharar (Mohali)

Turns property details + 4-8 real photos into a 20-40 s promo MP4 (1280x720, H.264 + AAC) - no video editor needed.

**Sample output:** `output/homeland_mohali_promo.mp4` - 25 s, 7 scenes, AI voice-over, built from 7 real Homeland Mohali photos (`sample_data/homeland_mohali/`).

## Setup
```bash
pip install -r requirements.txt     # Python 3.10+; ffmpeg is bundled via imageio-ffmpeg (a system ffmpeg is used if present)
python setup_voice.py               # optional: offline narration voice (~60 MB)
```
No MoviePy / pydantic needed - frames are drawn with Pillow + NumPy and encoded by ffmpeg.

## Run
```bash
python app.py                                   # builds the bundled Homeland Mohali sample -> output/homeland_mohali_promo.mp4
python app.py --property sample_data/homeland_mohali.json --out output/my_video.mp4
python app.py --name "Homeland Mohali" --location "Kharar, Mohali" --type Apartment \
  --features "Modular kitchen, Furnished bedroom" --cta "Book your site visit today." \
  --contact "Call 98xxx xxxxx" --price "Rs 45 Lakh" --images photo1.jpg photo2.jpg photo3.jpg photo4.jpg
streamlit run app.py                            # web form: upload photos, preview, download MP4
```
Photos are used in the order given: first = opening scene, last = closing enquiry scene, the rest = feature scenes (one per feature).
Input JSON fields: `name`, `location`, `property_type`, `price`, `features`, `cta`, `contact`, `images`.

## How it works
1. **Script** - template logic (offline, deterministic) writes captions + voice-over from *only* the supplied fields.
   Optional `--llm` (Gemini `gemini-2.5-flash` or OpenAI `gpt-4o-mini`, via `GEMINI_API_KEY` / `OPENAI_API_KEY`) is fact-checked:
   output containing numbers not in the input is rejected and the template is used. The sample uses the template (no model).
2. **Narration (AI voice-over)** - per-scene TTS so each scene lasts as long as its line: `edge-tts` (en-IN-NeerjaNeural, best quality, needs internet) ->
   `Piper` offline -> `gTTS` -> `flite` (basic robotic offline voice built into ffmpeg) -> none. **The bundled sample was rendered offline, so it uses
   the basic `flite` voice; run `python app.py` with internet for the natural Indian-English neural voice.**
3. **Video** - Pillow/NumPy + ffmpeg: cover-fit or blurred-fill photos, slow zoom, fade-in caption banners, cross-dissolves, intro/feature/outro structure.
4. **Music** - a soft royalty-free ambient bed generated by `tts_engine.py` (no licence issues); drop your own `assets/ambient_bg.mp3` to replace it.

## Missing / bad input
Price and contact are optional (left out of the video). Missing files and corrupt images are skipped with a warning; fewer than 4 photos still
works (photos reused); more than 8 are trimmed; no usable image, or missing name/location, prints a plain `ERROR:` message (exit code 2), never a stack trace.

## Notes on the sample data
- Price and contact were not supplied, so none appear in the video. Captions only describe what is visible in the photos
  (living room, kitchen, bedrooms, bathroom, terrace) - verify against the actual unit before publishing.
- The opening exterior image is a developer render, and the kitchen/bathroom/terrace photos are small (200-300 px) so they look softer;
  higher-resolution originals will look better.
- Two supplied photos are in `sample_data/homeland_mohali/not_used/`: one shows the "HOMELAND" sign on the building and one is a sea-view pool
  that doesn't appear to be from the project. Add them to `homeland_mohali.json` if you want them in the video.
